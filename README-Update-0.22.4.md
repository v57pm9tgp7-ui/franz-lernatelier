# Franz Lernatelier – Update 0.22.4

Dieses Update korrigiert die Druckfunktion in **Woche 38 · Übung 6 «Mon texte final»**.

## Änderung

- Die Druckfunktion **«Sprechkarte drucken»** steht jetzt **direkt unterhalb des grossen Textfeldes**.
- Beim Klicken auf Drucken wird der aktuelle Inhalt des Textfeldes nochmals ausdrücklich gespeichert.
- Die Druckfunktion erhält den aktuellen Text zusätzlich direkt übergeben. Dadurch hat der sichtbare, bearbeitete Text immer Vorrang vor einer älteren gespeicherten oder automatisch erzeugten Version.
- **Änderungen, Ergänzungen und Streichungen** im Textfeld erscheinen deshalb genau so auf der Rückseite der Druckkarte.
- Die Vorderseite enthält weiterhin die kompakten Stichwörter; die Rückseite enthält den aktuell bearbeiteten vollständigen Text.
- Der Browser-/Offline-Cache wurde auf Version `0.22.4` erhöht, damit keine alte Fassung der Druckfunktion geladen wird.
