FRANZ LERNATELIER – UPDATE SPRECHTRAINING WOCHE 36
=====================================================

Was wurde ergänzt?
-------------------
Mission 02 «Comment ça va ?» – Aufgabe D «Sprechtraining» erhält neu:

1. einen klaren Gesprächsfahrplan mit fünf Schritten
   Start → fragen → antworten/zurückfragen → reagieren → verabschieden
2. ein vollständig sichtbares Modellgespräch
3. drei Trainingsrunden mit abnehmender Unterstützung
   Runde 1: mit Hilfe
   Runde 2: weniger Hilfe
   Runde 3: möglichst frei
4. eine Zusatzhilfe für längere Gespräche:
   «Pourquoi ?» / «parce que …»
5. einen Rettungssatz:
   «Est-ce que tu peux répéter ?»

Installation im bestehenden GitHub-Projekt
-------------------------------------------
Dieses ZIP ist ein gezieltes Update für das aktuelle Repository «franz-lernatelier».

1. ZIP entpacken.
2. Den Ordner «public» in das bestehende Repository kopieren.
3. Die vorhandene Datei
   public/assets/module-bridge.js
   durch die neue Datei ersetzen.
4. Commit nach GitHub hochladen.
5. Die bestehende Cloudflare-Bereitstellung kann danach wie bisher deployen.

Wichtig:
Dieses ZIP enthält bewusst nur die geänderte Datei und diese Anleitung.
Es ist kein vollständiger Neuaufbau des Projekts und soll in das bestehende
Repository übernommen werden.

Technische Hinweise
-------------------
- Der bestehende Woche-36-Code wird nicht verändert.
- Gespeicherte Lernstände bleiben unberührt.
- Der bestehende 30-Sekunden-Timer und die drei Häkchen bleiben erhalten.
- Die Hilfe wird nach einem Niveauwechsel automatisch wieder eingeblendet.
- Responsive Darstellung für Notebook, Tablet und Smartphone.
